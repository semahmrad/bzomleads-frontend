Reference

API Documentation

GET /api/ask

Send the prompt through the query string.

GET /api/ask?prompt=hello

POST /api/ask

Send a JSON body from Angular or any frontend client.

{
  "prompt": "hello from my custom gemini api"
}

Response

The proxy returns the original prompt and the parsed text-only Gemini answer.

{
  "prompt": "hello from my custom gemini api",
  "response": "text only from Gemini"
}

CORS

  • Access-Control-Allow-Origin: *
  • Access-Control-Allow-Methods: GET, POST, OPTIONS
  • Access-Control-Allow-Headers: Content-Type, Authorization
